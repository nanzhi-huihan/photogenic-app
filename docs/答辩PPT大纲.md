## 第3页 — 研究背景

**选题背景：**
- 智能家居市场规模突破120亿元，年增长率>15%
- 传统机械锁存在安全隐患：钥匙丢失、无法追溯、权限管理困难
- 用户对门禁的需求从"开锁"升级为"智能管控"

**研究意义：**
- 多模态识别：五种开锁方式，灵活适应不同场景
- 智能安防：多层次报警策略，主动安全防护
- 远程管理：BLE+手机APP，随时随地监控管理

## 第8页 — 系统工作流程

```
用户发起身份验证
       │
       ├─ 密码 → 比对 → 通过 → 开锁
       ├─ 刷卡 → UID查询 → 权限检查 → 开锁
       ├─ 指纹 → AS608比对 → ID查询 → 开锁
       ├─ 人脸 → K210识别 → ID查询 → 开锁
       └─ 蓝牙 → 配对检查 → 开锁
                    │
              验证失败 → 计数+1
              ≥3次 → 报警触发
                    │
              成功 → 记录日志 → BLE上报
```

## 第9页 — 软件架构

**主循环 + 中断架构：**

- 主循环（10ms周期）：蓝牙处理 / 按键扫描 / 门磁检测 / 自动关门 / OLED刷新 / DHT11采集
- TIM2中断（1ms）：系统tick + RTC
- USART2中断：BLE数据接收（帧解析）
- USART3中断：指纹模块数据
- EXTI中断：门磁变化 + 出门按钮

---

## 第10页 — 蓝牙通信协议

**帧格式：**

```
[0xAA] [CMD] [LEN] [DATA...] [XOR]
帧头    命令  长度   数据域    校验
```

- 下行（APP→门锁）：开锁/关锁/管理 0x01~0x7F
- 上行（门锁→APP）：应答/事件/数据 0xA0~0xDF
- 校验方式：XOR（Cmd ⊕ Len ⊕ Data[]）
